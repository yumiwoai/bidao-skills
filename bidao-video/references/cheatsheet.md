# 决策规则速查 — 毕导科普短视频创作方法论（40个视频ASR转写语料蒸馏）

| 能力 | 一句话规则 |
|---|---|
| 反常识选题双轨（常识翻盘×怪题严肃化） | 选题入库两问：答案能否当场翻盘？问题够贱能否配博士级严肃？ |
| 开场15秒反常识钩子 | 前15秒必须抛出与直觉冲突的悬念句，禁自我介绍与背景铺垫 |
| 庄谐落差（小学二年级反讽×学术化升级宣言） | 高深内容说成小学二年级，玩梗内容宣布学术化研究，一降一升 |
| 观众参与装置（弹幕扣数×思考题征集） | 争议处插扣1扣2站队，结尾抛观众回家能亲手验证的思考题 |
| 预判-反驳装置 | 先替观众说出错误答案再当场推翻，并给错误答案以敬意 |
| 跨期伏笔与DLC连载 | 结尾给下期挖坑，未定论明打DLC标签，跨视频回收成连续剧 |
| 七段式口播骨架 | 钩子-预判-递进-实证-反转-升华CTA，七段骨架套任何题材 |
| 第N层认知递进 | 「第1层/第2层/第3层」明示编号递进，每层推翻上一层 |
| 同构大一统 | 「这哪里是A，这分明是B」——同一结构统一无关现象并上画面 |
| 科学纠错栏目（打假×教材审查×自我打脸） | 把纠错做成常设栏目：复述权威→重做实验→纠偏，自我打脸同等隆重 |
| 伪学科命名体系（含拟人封号） | 「正经学科名+荒诞对象」造词建学科，配学科史与衍生分支 |
| 结尾三段式（升华×CTA×彩蛋） | 升华金句→固定三连CTA→10秒内彩蛋，三段顺序固定 |
| 商单桥接（知识延长线滑入） | 70-80%进度处沿知识延长线滑入商单，产品被当实验对象 |
| amazing口癖与预期纪律 | 只在实验成功/理论命中瞬间释放Amazing，失败平淡处严禁 |
| 最小对照实验设计 | 顺手做最小对照实验，对照组同框给差值字幕，常拿自己当对照 |
| 出处考证链 | 追溯说法到原始出处，引用树可视化每一跳谁改了什么 |
| 释怀系列概率安慰 | 用概率模型证明你的霉运是数学必然，看完你会释怀 |
| 期内留存钩 | 中段埋「看到最后」式悬念，钩子必须挂在未解决的子问题上 |
| 理想化建模与数量级估算 | 对象理想化只做数量级估算，结论给10的幂次并自嘲误差 |
| 尺度跃迁与还原论反转 | 跨尺度跃迁讲同一原理，收尾反转「越微观越根本」直觉 |
| 一理多象应用枚举 | 原理讲完一口气排比枚举N个行业应用，给原理办荣誉证书 |
| 思想实验情景剧化 | 抽象概念改成有角色道具的剧，用「你」当主角写进实验装置 |
| 亲自下场实验与低成本复刻 | 能动手的绝不只讲文献，装置出镜翻车不剪，给观众低成本复刻入口 |
| 竞争假说淘汰赛 | 多假说并列，设计判别性实验逐一证伪，每轮淘汰是一次反转 |
| 实测统计自制数据集 | 为小问题亲手造数据集，样本量当场报出，低样本诚实自标注 |
| 理论-模拟-实测闭环 | 理论推导→哥们儿模拟→实测闭环，三者差异本身做成知识点 |
| 文献串讲与学术八卦 | 按时间线串讲论文配研究者八卦，每段八卦必须回收知识点 |
| 科学家人物暗线叙事 | 以科学家命运为暗线让知识有情感载体，人物低谷对应技术瓶颈 |
| 开放问题呈现 | 摆足两派最强论据后明说「我不知道」，拒绝对未定论下结论 |
| 经典文本科学重读 | 按字面接受经典设定，用现代科学逐条检验，得两极结论 |
| 可操作指南交付与适用范围声明 | 结尾给可执行清单，每条是前文知识压缩包并声明适用范围 |
| 日常决策建模 | 生活决策建成数学模型给最优策略，代入本人数据自嘲验证 |
| 母题题材宇宙与系列互引 | 反复回归同一母题做系列，跨视频互引串成题材宇宙 |
| 生活类比降维与失效边界 | 用生活物件类比抽象概念，必做「类比失效边界」自查 |
| 进度条元叙事 | 拿进度条自指视频结构造梗，把媒介本身当叙事素材 |
| 自嘲双轨（失败人设×科研圈内吐槽） | 失败经验即研究动机，圈内黑话吐槽建制，先自毁权威再输出 |
| 证据分级与模型前提声明 | 引用先报证据等级，建模先报前提三件套，失配当众放弃模型 |
| 失败叙事四拍编排 | 失败按预期-操作-翻车-复盘四拍编排，翻车不切镜头 |
| 技巧回溯第一性原理 | 对生活技巧追问为什么有效，从原理反推更优技巧 |
| 网络争议对线双轨 | 可证伪的复现测量回应，不可证伪的当众宣布弃权不辩 |
| 感知与物理量分离 | 拆开主观感知与客观物理量，给感觉找可测量的代理量 |
| 安全结论量化阈值 | 不答「危险吗」，只答「多危险、什么条件下危险」 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
