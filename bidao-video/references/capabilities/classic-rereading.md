# 经典文本科学重读

## R — 原文锚点

> 孙悟空嘲笑他：这个妖精是个外行啊……原著里孙悟空说的是给难粘的东西。

— 毕导，《【毕导】蒸唐僧怎么才能最快熟？没想到我竟然从西游记里学会了传热学！》[00:23、04:17]

## I — 能力自述

我专门处理全民记忆级的经典文本：名著桥段、寓言、课文、电视剧台词。所有人都记得这些文本，但没有人认真检验过它们——这正是传播势能所在。

我的契约是：输入一个全民文本，输出三步——按字面接受设定（不替古人圆场、不修正原文）→用现代科学逐条检验（实验/计算/几何推导）→交付两极结论：「古人早懂了」或「骗了我们很多年」。原文关键句要上字幕，检验点要具体到可裁决。

判停标准：是否按字面接受设定、结论是否两极、检验点是否可实验裁决。替古人打圆场、或结论骑墙「各有道理」，都是违约。

## A1 — 语料案例

### 案例 1: 《蒸唐僧怎么才能最快熟？》（西游记×传热学）
- **字面设定**: 蒸笼蒸唐僧，86 版台词「给难粘的东西」制造了一代人的错误印象（ce-06）
- **逐条检验**: 传热学分析水汽凝结放热，实测蒸包子下层先熟——「上层先熟」的直觉被实验否决
- **两极结论**: 妖精被判「外行」，影视改编台词与原著的边界当场声明

### 案例 2: 《科学打假！乌鸦喝水的寓言竟然骗了我们这么多年！》（伊索寓言×几何密堆）
- **字面设定**: [01:26]「伊索寓言里并没有说石子的堆积方式」——按字面接受「扔石子」设定
- **逐条检验**: 计算球体密堆体积占比是三分之π，随机投掷效率更低
- **两极结论**: 寓言方向正确但效率存疑——乌鸦得先懂密堆积才能喝到水

### 案例 3: 《曹操竟是古代第一基建狂魔？〈三国〉的一夜筑冰城真的可行吗？》（三国演义×传热学验算）
- **字面设定**: [01:21]「沙子泼水真的能造出马超都冲不破的冰墙吗」——接受「一夜」与「泼水冻沙」双承诺
- **逐条检验**: 冻湿沙实测「俩小时过去了，几乎冻不上」（ce-10，毛细管过冷水机制）
- **两极结论**: 工程路线存在但「一夜」不可行——翻车本身就是两极结论的素材

## A2 — 触发场景 ★

### 用户会在什么情境下需要这个 skill?

1. 名著桥段检验：「西游记里的操作可行吗」
2. 课文/寓言重读：「乌鸦扔石子到底有没有用」
3. 历史传说工程验算：「一夜筑冰城是不是真的」
4. 电视剧台词考据：「从小看到大的这一幕科学吗」

### 语言信号

- 中文信号：「古人是不是早就懂了」「课本/电视上说的对吗」「骗了我们这么多年」「按原著设定」
- 英文信号：classic rereading / myth-busting a classic / cultural IP

## E — 可执行步骤

1. **选文本**
   - 完成标准: 全民记忆级文本（名著/寓言/课文/爆款影视剧），检验点具体可实验
2. **按字面接受设定**
   - 完成标准: 列出文本的全部字面承诺（一夜、泼水、上层先熟），不圆场不修正
3. **拆检验点**
   - 完成标准: 拆出 2-3 个可用实验或计算裁决的子问题，每个点写出「什么结果算什么结论」
4. **逐条检验**
   - 完成标准: 每条给出实验数据或计算过程；原文关键句上字幕，影视改编处声明改编与事实的边界（ce-06）
5. **出两极结论**
   - 完成标准: 结论落在「古人早懂了/骗了我们很多年」两极之一；检验发现翻车不回避，翻车本身就是结论素材（ce-10）
6. **判停**
   - 完成标准: 字面接受 ✓+逐条检验 ✓+两极结论 ✓——三条全过才收工；检验点牵强（只为蹭 IP 硬找挂靠）则弃题；结论骑墙则回步骤 5 重写

## B — 边界与失效条件 ★

### 不要在以下情况使用此 skill

- 文本知名度不足：小众文本没有传播势能，检验再扎实也无人共情
- 检验点牵强：为联动 IP 硬找科学挂靠点，观众一眼看穿
- 结论只能骑墙的公案：先检查是否漏了解释层级（ce-33 两小儿辩日四层结构），确认无定论则转开放问题处理（ce-19），不硬造两极

### 相关反例

- ce-06（影视台词覆盖事实）：引用影视/文学桥段讲科学必须声明改编边界，多机制现象禁止单机制直觉外推
- ce-10（冻湿沙翻车）：复现类选题先做最小原型实验再承诺可行性，失败后改方案不硬刚
- ce-19（骑墙式理中客）：重读文本若得出「各有道理」，等于没读
