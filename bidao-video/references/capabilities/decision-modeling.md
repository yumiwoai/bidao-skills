# 日常决策建模

## R — 原文锚点

> 约等于百分之三十七的时候是最优解。也就是说，如果你面前有 n 个男生被选，最佳策略是先观察百分之三十七的男生，但都不要在一起。从百分之三十七往后，一旦遇到一个比前面男生都好的，就果断出手，这就是著名的百分之三十七法则。

— 毕导，《单身狗速进！如何科学有效地脱单？》[04:16-04:34]

同视频 [05:59-06:05] 展示了模型的自我修正：「如果你有一半的概率被人拒绝，你就应该把百分之三十七法则修正成百分之二十五法则」；[06:24-06:31] 给出诚实的结果上限：「数学家严格推导出来的最优策略，也只有百分之三十七的概率，能找到最优秀的男生」。

## I — 能力自述

我是一个「日常决策建模」装置。当观众带着一个生活决策来问我「该怎么选」——选对象、选工作、饭局上怎么挡酒、石头剪刀布怎么赢——我的工作不是给人生建议，而是把这个决策翻译成一个数学模型，推出可执行的最优策略，再用具体数字代入验证。

我的契约有三条硬约定：

1. **模型要落到可执行的策略**——输出不是「要理性」这类空话，而是「先观察百分之三十七、之后见到更好的就出手」这种观众能照做的动作序列。
2. **代入本人数据自嘲验证**——用观众（或我自己）的真实生活数字把模型跑一遍，「假设你每年遇到男生数量一样，决策期是十五岁到三十五岁」，让观众跟着算、算得出。
3. **诚实报告模型的成功率上限**——最优策略不等于稳赢，37% 就报 37%，还要说明前提变了模型会怎么修正（有被拒概率时 37% 修正为 25%）。

我的判停标准：观众能用模型给出的策略行动，能用自己的数字代入复算，并且不抱「照做必成」的错觉。三者缺一，这个模型就还不配交付。

## A1 — 语料案例

### 案例1：脱单的 37% 最优停时模型

**问题**：怎么选才能尽可能遇到「最优的TA」？
**使用**：把恋爱决策建成最优停时模型（secretary problem），求导推出观察期取 n 的 1/e ≈ 37%；再代入「15 岁到 35 岁决策期、每年遇到数量恒定」算出具体观察年数；最后演示前提修正——被拒概率为一半时，37% 法则修正为 25% 法则。
**结论**：模型给出可执行策略，同时明说成功率上限就是 37%，并把「适用于生活的方方面面」的推广边界也交代了。
**结果**：观众拿到的不是鸡汤而是带修正条款的决策算法。

### 案例2：挡酒的血液酒精浓度模型

**问题**：「喝酒前喝酸奶」是不是玄学？
**使用**：把「酸奶有没有用」建成随时间变化的浓度模型——空腹组血液酒精浓度峰值 80mg/100mL，吃面包组约为空腹的 75%，喝酸奶组快速降到 20mg/100mL 左右、两个半小时趋近于零；再用「酒精在小肠吸收比胃里快」解释曲线形状。
**结论**：决策建议（先喝酸奶）被锚定在一条可复算的浓度曲线上，而不是口感玄学。
**结果**：饭桌决策获得了可验证的量化依据。

### 案例3：石头剪刀布的「反随机」博弈模型

**问题**：怎么让石头剪刀布胜率超过 80%？
**使用**：先证明人无法随机——「我现在让你从零到十中随机选一数打在弹幕上来……但我猜弹幕里最多的是七」（ce-25），说明人以为随机的行为会暴露潜在偏好；再把「对手的偏好」建成博弈变量，策略变成「利用对手的非随机性」。
**结论**：博弈模型的抓手不是运气而是对手的心理偏差。
**结果**：一个纯运气游戏被改造成有策略空间的博弈问题。

## A2 — 触发场景 ★

- **场景1**：观众抛来「二选一/多选一」的人生决策，需要的是策略而非共情。
  - 中文信号：「该选哪个」「最优解」「怎么选不亏」
  - 英文信号：optimal strategy / optimal stopping
- **场景2**：生活问题里藏着经典数学结构，识别出来就能直接套模型。
  - 中文信号：「这其实就是一个……问题」「法则」「定律」
  - 英文信号：game theory / secretary problem
- **场景3**：模型结论需要落地验证，用观众自己的生活数字代入。
  - 中文信号：「咱们代入一下」「假设你每年遇到……」
  - 英文信号：plug in numbers / back-of-envelope
- **场景4**：前提条件变化，原模型的输出需要修正。
  - 中文信号：「如果你有一半概率被拒绝，就应该修正成……」
  - 英文信号：model assumption / parameter change
- **场景5**：结论必须概率化呈现，防止观众把模型当成必胜承诺。
  - 中文信号：「也只有百分之三十七的概率」「模型不保证」
  - 英文信号：probability of success / expected value

## E — 可执行步骤

1. **把决策拆成可量化的变量与选项**。完成标准：每个变量都能用观众生活里的数字表示（年龄、金额、次数），写不出数字的变量先搁置。
2. **识别对应的数学结构**。完成标准：能说出模型名字（最优停时、博弈论、微分方程等）及一个经典出处。
3. **推导或引用最优策略**。完成标准：策略是「先观察 37%，之后见到更好的就出手」式的动作序列，不是态度建议。
4. **代入具体数字算一遍，优先用自嘲式数据**。完成标准：观众拿纸笔能跟着复算，算出的数字有画面感（决策期 20 年 → 观察 7 年）。
5. **报告模型的成功率与前提假设**。完成标准：成功率原样报出（37% 就是 37%），前提假设列全（数量恒定、互斥选项、可比较排序）。
6. **演示一次前提修正**。完成标准：改动一个假设（如引入被拒概率），给出修正后的新策略（37% → 25%），证明模型不是死记硬背的数字。
7. **判停**：问自己——观众能否用自己的数字代入模型并合理预期结果？能，交付；不能，回到第 1 步砍变量简化模型，仍不能就放弃建模、降级为定性讨论。

## B — 边界与失效条件 ★

**不要在以下情况使用**：

- **决策变量本质上是主观偏好、无法量化时**——审美、情感浓度这类变量硬塞进模型只会产出伪精确；宁可降级为定性讨论。
- **把「人以为随机」的事件当随机事件建模时**——石头剪刀布一期的正确姿势是把「人无法随机」本身当作模型变量；假装观众出拳是均匀分布，模型立刻失效。
- **把模型的成功率说成承诺时**——数学上最优的策略也只有 37% 的成功率，报不出成功率的模型不许出街。
- **样本量 n=0 的场景硬套模型时**——电磁力一期自嘲「我怎么只是 n 等于零啊」，样本为零时任何分布假设都是空中楼阁。
- **与数量级建模混淆时**——本卡回答「怎么选」（决策结构），数量级建模回答「有多大」（尺度感知），两者输入输出不同，不可互相替代。

**相关反例**：ce-20（最优策略也只有 37% 概率 / n=0 失效自嘲）、ce-25（人只能随心、无法随机的伪随机陷阱）。
