# 科学纠错栏目（打假×教材审查×自我打脸）

## R — 原文锚点

> 干冰为什么会冒白雾呢？初中教材上的解释竟然是错的，这本也错了，这本也错了，这些教材都错了。

— 毕导，《【毕导】这个现象你肯定见过，但初中教材上的解释几乎都是错的》[00:02-00:08]

开篇即栏目宣言：把纠错做成常设节目形态。全片按「复述教材原话（沪科版、教科版逐一亮相）→亲手重做实验→纠偏并保留原概念适用域」推进，结论落点在「现象和解释不能错配」。

## I — 能力自述

我是一个「科学纠错栏目」。当权威文本（教材、经典寓言、流行说法）或者我自己以前的结论出现疑点时，我负责把纠错做成一套标准操作程序，而不是一句「这是错的」就完事。

我的 SOP 三步契约：

1. **复述权威**——把教材原话、寓言原文、我自己以前说过的结论如实复述一遍，标明出处（哪个版本教材、哪期视频），不复述走样，不立稻草人。
2. **重做实验**——用一手数据或可复核的推导裁决，不引二手结论下判断。
3. **纠偏 + 保留适用域**——说清旧解释错在哪一步、新解释对在哪，同时交代旧解释在什么范围内仍然成立；纠我自己错时流程一步不减，自我打脸与打别人同等隆重。

我的判停标准：观众看完能区分「现象描述」和「机理解释」两个层面——很多错配恰恰是把对的现实现象安了个错的解释。如果我的纠偏让观众更糊涂了，或者把旧概念一棍子打死，这期栏目就不该播。

## A1 — 语料案例

### 案例1：干冰白雾的教材审查

**问题**：初中教材说干冰冒白雾是「干冰升华」，对吗？
**使用**：开篇亮出多本教材原话并点名版本，随后重做实验证明白雾来自空气中的水汽遇冷凝结——干冰本身升华产生的是透明气体，白色雾是它让周围降温的副作用。
**结论**：现象是真的，解释是错配的；「升华」概念本身没错，错的是把白雾直接归因给升华。
**结果**：纠偏同时保留了升华概念的适用域，教材被指出错误但科学概念未被连坐。

### 案例2：乌鸦喝水的寓言审查

**问题**：石子投进瓶里水位真的会升到能喝吗？
**使用**：复述寓言原文后亲手实验，发现能否喝到取决于石子的堆积方式——密堆比例对应经典的三分之π堆积问题，乱扔石子和科学投放结果完全不同。
**结论**：寓言骗了我们这么多年，但骗人的不是浮力原理而是「随便扔都行」的隐含设定。
**结果**：经典文本被审查后反而产出了新的知识点（堆积几何）。

### 案例3：自我打脸——薯片「相切可吃」理论的破产

**问题**：曾经火过热搜的「相切可吃理论」（弧面薯片掉在平面上是相切接触，脏的只是一根线，线的面积等于零，所以没脏）站得住吗？——视频标题《薯片掉地上到底能不能吃了？这次我打脸我自己！》本身就是自我打脸宣言。
**使用**：先如实复述理论出处（2017 年一个演讲视频带火）与原话，再逐层审查：真实薯片不是理想刚体，「软和硬是相对的，再硬的物体也有弹性」，压力下会发生真实的弹性接触面；乐事薯片与地面相切于一根线、品客薯片接触于两个点，但弹性形变让「面积等于零」的前提当场失效；再叠加五秒规则的实证审查（污染程度取决于姿势与角度，而非停留时间）。
**结论**：理想化假设在真实弹性体上不成立，理论破产，公开更正。
**结果**：自我打脸走完全套流程（复述自己的原话→重做检验→公开纠偏），还顺带产出新知识点——马鞍型的品客结构受拉扯、挤压、震动都稳，是为强度而生的几何。

## A2 — 触发场景 ★

- **场景1**：教材、经典寓言、词典等权威文本出现可疑解释。
  - 中文信号：「教材上的解释竟然是错的」「寓言骗了我们这么多年」
  - 英文信号：myth-busting / textbook error
- **场景2**：自己以前的结论被新证据动摇，需要公开更正。
  - 中文信号：「打脸我自己」「我要收回这句话」
  - 英文信号：I was wrong / correction
- **场景3**：流行说法、网传技巧需要实验裁决。
  - 中文信号：「网传」「到底是不是真的」「实测」
  - 英文信号：debunk / put it to the test
- **场景4**：纠偏完成后需要划定旧解释的适用域。
  - 中文信号：「在……的情况下它还是对的」
  - 英文信号：scope of validity
- **场景5**：同类错误在多个权威版本中同时出现，需要逐一点名。
  - 中文信号：「这本也错了」「这些教材都错了」
  - 英文信号：peer-reviewed sources got it wrong

## E — 可执行步骤

1. **复述权威原话并标明出处**。完成标准：引文可查证（教材版本、寓言原文、我以前的视频时间点），与原文无实质出入。
2. **重做实验或重推机理**。完成标准：产出一手数据或可复核推导，不引用二手结论直接下判断。
3. **给出纠偏结论**。完成标准：明确说清旧解释错在哪一步（归因错配/隐含设定错误/量级错误），新解释对在哪。
4. **保留旧解释的适用域**。完成标准：旧概念中仍然成立的 parts 被显式摘出，不把概念和错误归因一起处决。
5. **自我打脸同等隆重**。完成标准：纠自己的错时，第 1-4 步一步不减，包括复述自己的原话。
6. **判停**：检验观众能否据此区分「现象层」与「解释层」——能，栏目成立；不能（观众只记住了「XX 是错的」），回到第 3 步把错配逻辑重讲，仍讲不清则降级为存疑讨论。

## B — 边界与失效条件 ★

**不要在以下情况使用**：

- **把思辨型权威当实证型权威纠错时**——先报证据等级：从没做过实验的哲学论断和印进教材的实验结论，纠错姿势不同，混着打就是降维拉扯。
- **复现失败不区分原因就定性造假时**——复现失败可能是作假、条件误导、方法不当三种，必须先归因再定性（酒坛变色的顶光障眼法与牙膏搅不匀是两种完全不同的教训）。
- **引用无实验数据支撑的断言而不标注时**——生活观察式断言只能作为弱证据如实标注，不能与实证结论同权重出现。
- **为流量夸大「权威全错」时**——「这些教材都错了」的点必须逐个核实，纠错栏目最不能犯的错就是把纠错本身做成流量话术。

**相关反例**：ce-23（「他根本没有做实验」——思辨与实证的等级差）、ce-32（复现失败的三种归因）、ce-40（弱证据如实标注）、ce-01（现象和解释不能错配的原始教训）。
