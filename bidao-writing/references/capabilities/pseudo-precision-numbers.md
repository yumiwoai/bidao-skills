# 伪精确数字：用过载精度包装模糊感受

## R — 原文 (Reading)

> 睡意瞬间消了(1-1/e)。……截稿前我一共打了12937次瞌睡。……算出男主臂力1.2吨，我突然释怀的笑。
>
> — 毕导, 《这可能是我离退学最近的一次》/《如何一句话教老板做事》/《好多人讨论的〈逐玉〉，我算出男主臂力1.2吨》

## I — 方法论骨架 (Interpretation)

核心机制是**精度的错位**：困、气、累这类模糊主观感受，被配上明显超过其可测量上限的精度——小数点后一位、四位整数计数器、含 e 的公式、物理吨位。数学的严肃性反衬内容的荒诞，精度本身就是笑点；同时具体到个位的数字自带"有监控数据"的真实感，一箭双雕。
操作四步：找到初稿里只含形容词的情绪句（"我非常困"）→强行问"如果非要量化它是几"→选过载格式（小数/大整数/含 e 或 π 式子/物理单位四选一）→不动声色嵌入，**不解释、不补注**，让数字自己发言。
关键判据：数字的精度必须明显超过该感受的可测量上限（"血压上升42.6mmHg"成立，"血压有点高"不成立）；若数字在现实中真可测且合理，就要加码到更离谱的格式。

## A1 — 毕导的应用 (Past Application)

### 案例 1: 《这可能是我离退学最近的一次》——睡意消了(1-1/e)
- **问题**: "导师一说话我瞬间清醒"这种感受句太平
- **手法**: 用指数衰减常数 e 表达"醒了约63.2%"，把清醒程度写成一个数学式
- **效果**: 公式即笑点，理工科读者秒懂并截图传播，成为全文记忆点

### 案例 2: 《如何一句话教老板做事》——12937次瞌睡
- **问题**: "截稿前我特别困"是无信息量的流水账
- **手法**: 给困倦配一个精确到个位的计数器：截稿前一共打了12937次瞌睡
- **效果**: "很困"变成"有全程监控数据"，真实感与荒诞感同时拉满

### 案例 3: 《好多人讨论的〈逐玉〉》——臂力1.2吨
- **问题**: 吐槽影视剧动作夸张，单纯说"太假了"没有抓手
- **手法**: 煞有介事按杠杆原理测算，得出男主臂力1.2吨的吨位级结论
- **效果**: 测算结果直接进标题成为钩子，"我突然释怀的笑"配套出圈

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 初稿里有平淡的情绪句（我很困/我气死了/累惨了），想改成笑点
2. 测评/吐槽文缺一个可截图传播的金句
3. 细节描写想增加"真实感"颗粒度，让读者觉得"有数据"
4. 标题需要一个具体、有钩子的数字

### 语言信号

- "这句话太干了 / '我很困'怎么写得好玩"
- "给情绪配个数字 / 精确到小数点 / 具体到个位"
- "XX了多少次 / 百分之XX点XX / 上升了XX点X"
- "fake precision / overly specific numbers / quantify my feelings"

### 与相邻 skill 的区分（初稿）

- 与 `self-made-quantification` 的区别: 伪精确是**句子级**单点数字，给感受配过载精度、用完即弃；自造量化是**篇章级**体系工程，有公式、分级、排名，数字是体系的输出。
- 与 `mock-academic-packaging` 的区别: 伪精确可独立成句、不需要任何学术文体上下文；伪学术包装是整套语域的借用。一个是"数字错位"，一个是"文体错位"。

## E — 可执行步骤 (Execution)

1. **定位模糊感受句**
   - 完成标准: 在初稿中圈出所有只含形容词、无数字的情绪句（"非常困""气死我了""特别贵"）

2. **强行量化**
   - 完成标准: 每句改写为带数字版本，数字格式属于以下四类之一：小数点后1位 / 四位以上整数 / 含e或π的式子 / 物理单位（吨、mmHg）

3. **校验过载度**
   - 完成标准: 数字精度明显超过该感受的可测量上限（"看到第3.7秒血压上升42.6mmHg"通过）
   - 判停条件: 若数字现实中真可测且读感合理（"等了25分钟"），加码到更离谱格式，否则只是普通细节不是笑点

4. **控制密度与位置**
   - 完成标准: 全文伪精确笑点≤3处，分散在开头/中段/结尾不同位置，且不连续出现在同一段

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 数字无信息量或无反差时——为精确而精确会变成流水账（P-03 边界：尖冰冰13.5cm好笑是因为作者真的量了碎冰冰）
- 真正需要被当真的知识结论位——伪精确出现在结论位会被读者当真并引用，变成真误导

### 语料中的失败模式

- **单点数据不声明局限被打脸**（ce-54,《女生化一次妆有多贵》）: 单次测量没有误差范围，结论普适性不成立，专业读者会用更苛刻标准攻击——分界线在"情绪位随便精确，结论位必须声明粗粗计算"，伪精确只能待在情绪位。
- **通道冲突双双失效**（ce-39,《如何将任意辣鸡选题写成一篇超牛逼的毕业论文》）: PPT堆满文字，读字与听讲两个通道互相干扰双双失效——同理，一段里堆多个伪精确数字，笑点互相抢注意力，每个都不好笑。

### 局限

- 笑点依赖读者对"精度与感受错位"的敏感度；对数字不敏感的纯娱乐读者可能只当真、不觉好笑
- 含 e/π 的格式有圈层门槛，非理工读者接不住，需按读者画像选格式

### 容易混淆的邻近方法论

- `self-made-quantification`: 句子级单点（本 skill）vs 篇章级体系（彼 skill）
- `price-anchor-conversion`: 求过载笑点（本 skill）vs 求体感说服（彼 skill）
