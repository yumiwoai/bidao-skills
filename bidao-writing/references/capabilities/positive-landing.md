# 正能量兜底：玩梗之后的价值观安全着陆

## R — 原文 (Reading)

> 一切摸鱼动作，都是在保证工作我能搞定的前提下。否则你不仅会丧失工作摸鱼的乐趣，还可能丧失工作。……最后毕导要提醒大家，疫情封校虽然对生活有很大影响，但课程该学还得学，科研该做还得做！
>
> — 毕导, 《怎么摸鱼才不空虚？我从摩尔庄园中悟出了5大摸鱼要领》/《学校规定老师和学生不能有时空交集，我忽然有一计》

## I — 方法论骨架 (Interpretation)

全文教完摸鱼、糊弄、吐槽、投机这类"坏招"之后，必须在结尾补一小段一本正经的正确立场，把文章从"教坏读者"的边缘拉回安全区。操作配方四个要点：
① **固定排序先坏后好**——坏招在正文尽情发挥，正确立场只在结尾出现，顺序不可调换，否则全文沦为说教文；
② **篇幅极短**——两到四句话完成着陆，不展开论证，长了就是尾大不掉的说教尾巴；
③ **语气突变**——前文多不正经，这段就多正经，靠语气落差让读者明确识别"作者立场其实是对的"；
④ **内容一一对应**——把正文教过的坏招逐类配一句"正确姿势"（摸鱼→先把工作搞定、水组会→组会本质是督促科研、讲基金→评估风险谨慎投资），不新增观点。
这个装置一箭双雕：既规避价值观争议（防杠精上纲上线），又保住"自己人"人设（我不是真教你堕落）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《怎么摸鱼才不空虚？我从摩尔庄园中悟出了5大摸鱼要领》
- **问题**: 全文教5大摸鱼要领，收尾有"教坏打工人"的风险
- **方法论的使用**: 结尾立前提"一切摸鱼动作在保证工作能搞定的前提下"，再补刀"否则你可能丧失工作"
- **结论**: 教坏与自保一次完成
- **结果**: 读者记住的落点是"摸鱼要先搞定工作"这一正确立场

### 案例 2: 《科研毫无进展，如何堂堂正正地水组会？导师听完乐坏了》
- **问题**: 教人水组会，涉及对科研态度的价值观风险
- **方法论的使用**: 玩梗全文后落回一句"组会的本质是督促大家好好科研"
- **结论**: 吐槽内容安全着陆
- **结果**: 连导师读者也挑不出毛病

### 案例 3: 《基金大亏故事：朋友两年亏掉200w，这是他的心得》
- **问题**: 消费他人投资痛苦的段子合集，易被指"拿亏损开玩笑"
- **方法论的使用**: 结尾一本正经提醒"大家一定要评估好风险，谨慎投资！"
- **结论**: 在笑声落点处完成风控着陆
- **结果**: 规避"诱导/消费亏损"争议，文章立场无懈可击

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写完摸鱼/糊弄/吐槽/整蛊/投机类"教坏"教程：「这结尾怎么收才不会教坏读者」
2. 文章调侃了学校/导师/老板/品牌，发布前心虚：「这么写会不会被当真、被冲」
3. 全文都在玩梗，缺一个立场锚点：「怎么让读者知道我不是真坏」
4. 编辑/甲方/平台提示"价值观风险"，需要最低成本补刹车

### 语言信号

- "结尾怎么收/怎么落地/怎么圆回来"
- "会不会教坏读者/被杠/被上纲上线/三观不正"
- "补一句正能量/升华一下/把立场拉回来"
- "how to land the ending / play it safe / positive takeaway / values check"

### 与相邻 skill 的区分（初稿）

- 与 `anti-climax-ending`（结尾消解反转）: 本 skill 负责"从坏升到好"的安全着陆；消解反转负责在着陆之后"亲手拆掉升华"防煽情。同一结尾里先兜底、再消解，顺序固定（先正后皮）。判断标准：怕的是"价值观风险"用本 skill；怕的是"太像鸡汤"用消解反转。
- 与 `caution-dosage-note`（慎用提示）: 本 skill 是结尾段落级的总刹车；慎用提示是逐条技巧末尾的剂量标注。粒度与位置均不同。

## E — 可执行步骤 (Execution)

1. **判定选题敏感度**
   - 完成标准: 回答"正文是否教了坏招/调侃了真实对象/涉及钱与风险"——任一为是则必须兜底
   - 判停条件: 若全文正能量已贯穿（如温暖叙事文），标记"无需兜底"直接结束，避免重复说教

2. **回收坏招清单**
   - 完成标准: 列出正文教过的全部"坏动作"，每一类配一句对应的"正确姿势"，主要招式无遗漏

3. **写着陆段**
   - 完成标准: 用一本正经语气写2-4句，句式参照"虽然本文都在X，但Y该做还得做/一切X的前提是Z"；删光玩笑成分，读起来像班主任讲话

4. **卡篇幅与位置**
   - 完成标准: 着陆段不超过全文5%，位于正文之末、互动区之前；通读确认先坏后好的顺序没有颠倒

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 正能量本身已贯穿全文（如《高龄博士的一些意想不到的温暖》走温暖路线）——再兜底就是重复说教
- 纯搞笑无诱导性的内容——没有"坏招"就没有要兜的底
- 真正严肃的风险告知（实验安全、医疗建议）——此时正确立场必须是正文主角，不能只在结尾点缀

### 作者在语料中暴露的失败模式

- 刹车踩得太晚：被质疑后才补立场，公信力已受损（对照 ce-54 的教训：局限声明应在开始前而非被质疑后，价值观兜底同理，要在发布前内置）
- 不兜底导致技巧被滥用：缺刹车声明的钻空子教程，读者会把应急技巧当常态（对照 ce-08"每次都糊弄，开学不会好过"：糊弄话术被当长期策略，信任额度被逐次透支）

### 作者的盲点 / 局限

- 兜底只能降低争议概率，不能真正免责；涉及具体人/机构的攻击，结尾一句"我是好人"挡不住
- 与消解反转连用时，立场会被最后那句玩笑再次稀释，严肃选题慎用此组合

### 容易混淆的邻近方法论

- `anti-climax-ending`: 一个补正能量、一个拆正能量，功能相反而固定连用，顺序不可颠倒
- `disclaimer-device`: 免责声明切割的是事实与法律责任；正能量兜底稳住的是价值观立场
