# 第一人称自嘲人设：把自己写成穷人菜鸡，与读者同一战壕

## R — 原文 (Reading)

> 大家别觉得我小气，再小的肉也是肉，能点进这个推送说明大家生活都不富裕。……科目二一次考试有2次机会，这说明我其实考挂了7次……我就是我们家庭的耻辱，社会的败类。
>
> — 毕导, 《如何做一个体面的穷人》/《我竟然用3秒就擒拿了小偷》

## I — 方法论骨架 (Interpretation)

核心机制是**姿态设计**：作者主动走下神坛，把自己写成穷人、菜鸡、考挂7次的家庭耻辱，站在与读者同一战壕甚至更低的位置，绝不好为人师。先踩自己，再踩世界就安全——自嘲是为后面的毒舌与教学购买"自己人豁免权"。
两档操作：
① **第一人称自我矮化**——找出选题涉及的身份维度（财富/学术/颜值/车技），在该维度上先把自己踩到地板，最好一句话把读者也划进同一战壕（"能点进来说明大家都不富裕"）；
② **第三人称自称**——自称"毕导"，形成"本台记者为您报道"的间离效果，把私人吐槽包装成客观播报，谦卑与自恋同时成立，适用于栏目播报、立规矩、自夸必须说出口的场合。
矮化必须落在具体细节（考挂7次、合点一份黄焖鸡），空泛的"我很菜"没有效力。

## A1 — 毕导的应用 (Past Application)

### 案例 1: 《如何做一个体面的穷人》——开篇划战壕
- **问题**: 教省钱技巧极易读成说教或哭穷
- **手法**: 开篇一句"能点进这个推送说明大家生活都不富裕"，把作者与全体读者划进同一贫穷战壕
- **效果**: 后续所有精打细算的教学毫无说教感，读者以"自己人"姿态接受

### 案例 2: 《我竟然用3秒就擒拿了小偷》——矮化垫底高光
- **问题**: 讲自己擒贼的高光故事，容易显得自我吹嘘
- **手法**: 先自曝科目二考挂7次、自封"家庭的耻辱社会的败类"，把姿态压到地板再进入高光叙事
- **效果**: 矮化与高光形成落差，擒贼时刻反而更亮，炫耀感被自嘲中和

### 案例 3: 全语料第三人称自称"毕导"（g-04）
- **问题**: 给自己立规矩、夸自己的内容怎么说出口不招烦
- **手法**: "为此毕导我整理了一套《打工人相亲基本礼仪》"，用第三人称把私人表达包装成栏目播报
- **效果**: "被观察的自己"产生间离喜感，自称方式本身成为人设符号

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要写经验分享/教学/攻略文，担心被读成说教或凡尔赛
2. 文章涉及对某群体的毒舌吐槽，需要先取得"自己人"豁免权
3. 开新号/开新系列，要确定全文的叙事姿态与人称口径
4. 手上有高光故事（成功、获奖、擒贼）想讲但怕招人烦

### 语言信号

- "怎么写教程不像在说教 / 不想显得凡尔赛"
- "自嘲 / 自黑 / 矮化自己 / 卖惨的分寸"
- "用第三人称写自己 / 人称视角怎么选 / 人设怎么立"
- "self-deprecating / relatable narrator / persona / avoid humble-brag"

### 与相邻 skill 的区分（初稿）

- 与亲身实验自嘲叙事（f28, 挂在 `empirical-writing`）的区别: 本 skill 是**全文恒定的姿态设定**（人设层），从开篇第一句就生效；实验自嘲是**事件层的现场描写**（带砧板进海底捞被围观），依附于具体事件。人设先于内容存在，现场自嘲是内容的产物。
- 与正能量兜底（V-16）的区别: 自嘲是开篇与全文贯穿的姿态，兜底是结尾的价值着陆，位置与功能都不同。

## E — 可执行步骤 (Execution)

1. **确定矮化维度**
   - 完成标准: 找出本文选题涉及的身份维度（财富/学术/颜值/车技/职级），选定1个作为自嘲锚点，与主题强相关

2. **写开篇自贬句**
   - 完成标准: 前200字内出现一句把自己置于该维度低位的句子，且顺带着把读者划进同一战壕（"能点进来说明大家都…"句式）

3. **配置人称口径**
   - 完成标准: 全文统一规则——过程叙事用"我"，栏目播报/立规矩/自夸处用第三人称自称，两种人称不混用
   - 判停条件: 若文章需要建立权威（招聘、正式公告），判停并切割（"以下文为准"），本 skill 不适用于该段

4. **校验豁免权覆盖**
   - 完成标准: 文中每一处毒舌吐槽之前，附近一处自我矮化都已就位；每处矮化都带具体细节（次数、金额、名次）而非空泛形容
   - 判停条件: 若连续两段出现自嘲句且无新细节支撑，删到每屏≤1处，防止卖惨感

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要建立权威感的正式场合（P-01 边界：招聘正文须切割"以下文为准"）
- 真正的严肃科普结论段——自嘲会稀释结论可信度

### 语料中的失败模式

- **场域错配的人设反被收割**（ce-37,《过年回家什么人设才让亲戚闭嘴》）: 在亲戚场域立"精致/富裕"展示型人设，会触发"能者多劳"的索取逻辑被戴上人傻钱多帽子——写作同理：在同龄同温层场域立高人设，读者会索取"你凭什么教我"；自嘲本质是低索取人设。
- **叙事层的错误示范**（ce-05,《北交实验室爆炸之后》）: 用炫耀口吻讲危险经历会在叙事层教坏读者——反向同理，自嘲若滑向"以丧为荣"的价值宣言也会传染，矮化必须落在具体细节上，不能变成身份标榜。

### 局限

- 长期单一自嘲人设会让读者把"穷/菜"当真，接高价商单时产生人设摩擦
- 真实成就需要借第三方之口或第三人称自称迂回说出

### 容易混淆的邻近方法论

- `empirical-writing`（含 f28 自嘲叙事）: 全文姿态（本 skill）vs 事件现场（彼 skill）
- 正能量兜底（V-16）: 贯穿全文的姿态（本 skill）vs 结尾单点着陆（彼 skill）
