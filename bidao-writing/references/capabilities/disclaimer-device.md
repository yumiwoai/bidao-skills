# 免责声明与边界声明：保命装置本身也是梗

## R — 原文 (Reading)

> （以上纯属胡扯，请校长不要开除我）……本文结论仅对这一片回锅肉和包菜负责。……以下仅为粗粗计算，仅供粗粗参考，不要太当真。
>
> — 毕导, 《学校规定老师和学生不能有时空交集，我忽然有一计》/《告食堂阿姨书：您再手抖我就去复读考清华了》/ g-28 免责声明体语料

## I — 方法论骨架 (Interpretation)

在调侃真实对象、发布小样本数据、或教授危险动作的文章里，免责声明是标准配置；毕导的独特处是把声明本身写成梗，让安全装置同时承担笑点与人设。操作要点：
① **先列风险清单再动笔**——真人/真机构/品牌/数据口径/危险教程，逐项过一遍，有哪项配哪项的声明；
② **位置三选**——前置（危险话题与数据口径，在开头或实验开始前声明）、随文（每个离谱提案后紧跟括号一句"纯属胡扯"）、文末（总结性"图一乐"）；位置原则是"被质疑之前先声明"，抢占定义结论适用范围的主动权；
③ **浓度与危险度成正比**——话题越危险，声明越显眼越反复（分手文连喊两句"请不要参考！"）；
④ **声明写成梗**——口语化撒娇（"算错了你来打我呀"）、限缩负责范围（"仅对这一片回锅肉和包菜负责"）、向大人物讨饶（"请校长不要开除我"）；
⑤ **敏感对象一律化名**——"海底掏（化名）"格式，括号标注化名二字，切割更彻底。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《学校规定老师和学生不能有时空交集，我忽然有一计》
- **问题**: 全文逐条推演调侃学校防疫政策，得罪校方的风险真实存在
- **方法论的使用**: 每个离谱提案后紧跟括号免责——"（以上纯属胡扯，请校长不要开除我）""（请导师看了不要把我踢出组群）"
- **结论**: 随文括号式切割，讨饶对象越具体越好笑
- **结果**: 免责声明白身成为全文记忆点，文章安全存活

### 案例 2: 《网上买菜比超市更贵吗？对比75种菜价我发现以前亏了一个亿》
- **问题**: 75种菜价对比是小样本调查，易被拿普适性打脸
- **方法论的使用**: 前置声明口径——"表中价格仅代表毕导在2022年5月9号-10号期间的实地调查及线上统计情况……仅供参考！"
- **结论**: 数据局限在发布前主动声明
- **结果**: 专业读者无从攻击，测评公信力反而增强

### 案例 3: 《跨年夜除了跨年还能做什么？来一场酣畅淋漓的分手吧！》（ce-55 正面示范）
- **问题**: 把"分手"这种高风险话题写成教程，存在读者当真的尾部风险
- **方法论的使用**: 前置高浓度声明——"本文纯属玩梗，毫无任何参考价值！请不要参考！"
- **结论**: 声明浓度与话题危险度匹配
- **结果**: 喜剧效果与责任切割同时达成

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 文章调侃了真实学校/公司/品牌：「这么写会不会被找麻烦」
2. 测评/数据文样本量小：「怕被人拿普适性打脸」
3. 教了钻空子/危险动作：「怕有读者真照做」
4. 要写免责声明：「怎么写才不像公文、不像心虚」

### 语言信号

- "免责声明/声明一下/保命/先叠甲"
- "化名/马赛克/不点名/别当真"
- "怕被杠/怕被打脸/怕有人照做/怕惹事"
- "disclaimer / for entertainment only / not advice / cover my back"

### 与相邻 skill 的区分（初稿）

- 与 `caution-dosage-note`（慎用提示）: 本 skill 是全文级/段落级的责任切割（"本文别当真"）；慎用提示是逐条技巧末尾的剂量标注（"这条一周用一次"）。粒度不同，可同篇共存。
- 与 `seamless-ad-integration`（软广植入）: 有广标广告、无广声明无广，两者共用信任逻辑但方向相反（ce-56：不声明边界的主观测评易被当成广告）。

## E — 可执行步骤 (Execution)

1. **列风险清单**
   - 完成标准: 逐项核对全文——真实人名/机构/品牌、数据与口径、危险教程、敏感话题，列成清单打勾

2. **给每项配声明与位置**
   - 完成标准: 清单中每项都标注声明位置（前置/随文/文末），危险话题的声明必须前置且显眼
   - 判停条件: 危险话题的声明写得比正文还隐蔽（小字、角落、含糊措辞）——判停，重写至一眼可见

3. **把声明改写成梗**
   - 完成标准: 每条声明至少用一招——口语化撒娇/限缩负责范围/向当事人讨饶，删掉所有法律公文腔

4. **敏感对象化名**
   - 完成标准: 全文搜索真实人名/品牌名，逐一替换为"XX（化名）"格式，无遗漏

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯虚构段子：无事实主张可免责（P-06 明确标注）
- 正式学术发表：玩梗式声明在正式文体中违规
- 真实的法律风险场景（诽谤、肖像权、泄露隐私）：声明挡不住真实侵权，该删的内容必须删

### 作者在语料中暴露的失败模式（反例支撑）

- ce-54 单次称量就下结论且不声明局限：被专业读者用更苛刻标准攻击，作者丧失定义结论适用范围的主动权——声明要在实验开始前而非被质疑后
- ce-55 危险话题写成教程不设防：教程文体自带"建议照做"的默示授权，评论区出现"我照做了"，现实后果回溯为作者责任
- ce-56 主观测评不做边界声明：小样本结论被外推为普适定论，招致"软文/以偏概全"质疑

### 作者的盲点 / 局限

- 玩梗式声明切割的是舆论责任，不具备法律效力；真到诉讼层面"请校长不要开除我"帮不上忙
- 声明过密会打断阅读节奏，14篇的分布密度说明它只用于真有风险的篇目

### 容易混淆的邻近方法论

- `caution-dosage-note`: 全文级责任切割 vs 条目级剂量标注
- `seamless-ad-integration`: 内容边界声明 vs 利益关系标注，一体两面
