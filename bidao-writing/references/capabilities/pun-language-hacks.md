# 语言梗化改造：谐音、魔改古诗与伪名言的三条产线

## R — 原文 (Reading)

> 沉默的是今晚的康桥，沉没的是导师的微笑。……忍一时风平浪静，退一步公司倒闭。……任何句子后加个破折号，就会变成一口锅，甩在了破折号后的那个人头上——鲁迅。
>
> — 毕导, 《研究生开组会时都是什么鬼样子，我总结了15种类型》/《如何培养一名高素质老板》/《聊天发错群，除了一头创死还能怎么办》

## I — 方法论骨架 (Interpretation)

语言本身成为笑点，有三条固定产线：
① **谐音换字**——在熟词/成语/古诗中换一个同音或近音字，新义与原义形成反差（"会当凌绝顶"→"会当您绝顶"，豪迈变秃头；"从长计议"→"从肠计益"，同时完成广告过渡）；
② **成语古诗魔改**——保留名句句式与节奏，替换关键词使语义滑坡（"忍一时风平浪静"接得住，"退一步公司倒闭"接不住）；
③ **伪名言落款**——先按名言句式严肃起句，再在落款处错位给鲁迅/尼采，或保持句式只换关键词（"以铜为镜可以正衣冠，以你为镜可以知下班"）。
**选材方法论**：底本必须取自全民最大公约数——义务教育课文、成语俗语、国民名言、当年热梗，读者零成本接住。
**铁律**：改造必须服务主题（点题/过渡/点评有明确业务目标），只音近而不贴主题的梗直接删除。

## A1 — 毕导的应用 (Past Application)

### 案例 1: 《研究生开组会图鉴》——康桥魔改
- **问题**: 15种类型的点评句需要金句收束
- **手法**: 把徐志摩"沉默是今晚的康桥"换一字，接"沉没的是导师的微笑"，一字双关研究生组会的死寂
- **效果**: 国民课文瞬间激活集体记忆，成为全文被引用最多的点评句

### 案例 2: 《如何培养一名高素质老板》——俗语反转
- **问题**: 吐槽老板的委屈需要一句有力道的总结
- **手法**: 借用"忍一时风平浪静，退一步海阔天空"的全民预期，后半句换成"公司倒闭"，预期违背即笑点
- **效果**: 打工人怨气被一句对仗优雅的伪格言接住，毒舌但体面

### 案例 3: 《线上办公实录》——古诗换字+伪尼采双连
- **问题**: 居家办公开会的痛苦需要点题句
- **手法**: "会当凌绝顶"换"凌"为"您"成"会当您绝顶"（吐槽开会头秃）；"每个不曾开会的日子都是对生命的辜负"挪用尼采句式
- **效果**: 一篇两处梗分别击中"会多"与"头秃"两个主题点，金句密度撑起全文传播

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 段落写完缺一句点题金句/可截图传播句
2. 标题、小标题想起得更好玩、更有记忆点
3. 广告植入需要一个不突兀的过渡梗
4. 想毒舌吐槽但要保持优雅体面

### 语言信号

- "帮我想个梗/金句/谐音梗/双关"
- "这句太平了想改得有趣 / 魔改一句诗/成语"
- "标题/小标题怎么起得好玩 / 想要可截图的句子"
- "pun / wordplay / parody quote / meme rewrite"

### 与相邻 skill 的区分（初稿）

- 与 `mock-academic-packaging` 的区别: 梗化改造是**句子级语言手术**（换字、谐音、伪引），手术对象是汉字与句式；伪学术包装是**文体级语域借用**，手术对象是整段的文体。梗看"语言"，包装看"文体"。
- 与招式命名体系（XX法）的区别: "XX法"是给攻略条目起名的固定后缀模板，是本 skill 命名功能的一个子集；本 skill 是自由造句的三条产线，适用范围大于条目命名。

## E — 可执行步骤 (Execution)

1. **确定梗的业务目标**
   - 完成标准: 写下这句梗要完成的功能（点题/过渡/点评/标题钩子），无目标的梗位直接删除
   - 判停条件: 若该段落是严肃内容（安全提醒/真实结论/抒情），判停，本段不造梗

2. **选底本**
   - 完成标准: 从全民公约数底本（义务教育课文/成语/俗语/名言/当年热梗）选定一句，随机抽查一个目标读者能脱口而出

3. **执行改造**
   - 完成标准: 按三条产线之一产出新句：谐音换字（音同或音近）/ 保留句式换关键词 / 保留句子换落款

4. **校验双层成立**
   - 完成标准: 新句同时成立两层——读者能识别原句记忆，且替换字与本文主题直接相关
   - 判停条件: 若只成立"音近"一层、与主题无关，放弃该梗，不硬凑

5. **控制密度**
   - 完成标准: 每屏（约500字）梗化句≤1处，全文谐音类≤3处，三条产线混用不重复

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 连续堆砌——一篇里高频谐音会让读者疲劳（P-11 边界）
- 严肃段落（安全提醒、哀悼、真实科普结论）——梗会稀释信息可信度

### 语料中的失败模式

- **浓度失控被当真**（ce-55,《跨年夜除了跨年还能做什么》）: 教程体自带"建议照做"授权，玩梗话题越危险（分手/离职），梗的浓度越要夸张到不可能被当真，并反复声明"本文纯属玩梗，毫无任何参考价值"——浓度与危险度成正比。
- **形式预算错配评价体系**（ce-38,《如何将任意辣鸡选题写成一篇超牛逼的毕业论文》）: 形式华丽度超过内容承载力会被批"弄巧成拙"——干货文里每段一梗，读者会读成"没东西硬凑"，梗的密度预算必须匹配读者对本文的内容期待。

### 局限

- 谐音梗依赖中文语音与共同课文记忆，翻译后或非中文读者完全失效
- 热梗底本有保鲜期，当年的流行语次年即显陈旧

### 容易混淆的邻近方法论

- `mock-academic-packaging`: 句子级语言手术（本 skill）vs 文体级语域借用（彼 skill）
- 招式命名体系（XX法）: 本 skill 的子集，专攻攻略条目命名
