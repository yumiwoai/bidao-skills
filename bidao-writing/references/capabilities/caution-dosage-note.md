# 慎用提示：坏技巧的剂量标注与二次造梗

## R — 原文 (Reading)

> 老板是单独办公间的话就不必强求了……唯一的缺点就是有点费老板。……摸鱼群人数不要太多，如果是300个人加入，公司可能就会倒闭。……拉肚子时慎用，别问我为什么。
>
> — 毕导, 《老板勿进！上班如何打瞌睡不被发现》/《怎么摸鱼才不空虚》/《救命！跟老板同时在厕所蹲麻了，除了辞职还能怎么办》

## I — 方法论骨架 (Interpretation)

技巧教学清单文在逐条给出「坏招」之后，每条末尾顺手挂一句边界标注——这招什么时候失效、用到什么剂量封顶、哪类人禁用。毕导的独特处是把这句提示本身写成笑点，让分寸控制装置同时是喜剧装置。操作要点：
① **位置紧跟条目末尾**——不汇总到文末集中声明，挂在每条技巧后面当固定后缀，读者对号入座；
② **标注三选一**——失效条件（「老板是单独办公间的话就不必强求了」）、剂量上限（「摸鱼群人数不要太多，300人公司可能就会倒闭」）、禁用人群（「严肃导师不适合」）；
③ **提示写成梗**——用夸张后果（「有点费老板」）或欲言又止（「别问我为什么」）替代说明书腔，把药品说明书式的「慎用」二字改造成包袱；
④ **双功能设计**——既是真诚的分寸控制（防读者滥用透支信任），又是一次额外的抖包袱机会，一条提示两个用途；
⑤ **语气轻描淡写**——用顺带一提的口吻，越不当真越显真诚。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《老板勿进！上班如何打瞌睡不被发现》
- **问题**: 教读者上班打瞌睡不被发现，技巧本身有真实职场风险
- **方法论的使用**: 逐条标注失效条件——「老板是单独办公间的话就不必强求了」，并附夸张代价「唯一的缺点就是有点费老板」
- **结论**: 把风险边界换算成喜剧计量单位（费老板）
- **结果**: 提示本身成为全文传播度最高的梗之一

### 案例 2: 《怎么摸鱼才不空虚》
- **问题**: 教建摸鱼群，群规模失控有真实后果
- **方法论的使用**: 标注剂量上限——「摸鱼群人数不要太多，如果是300个人加入，公司可能就会倒闭」
- **结论**: 剂量标注用离谱外推的方式呈现（300人→公司倒闭）
- **结果**: 边界说清了，笑点也留下了

### 案例 3: 《除夕将至如何高情商地给导师拜年》+《救命！跟老板同时在厕所蹲麻了》
- **问题**: 话术类教程，不同对象/不同身体状态下后果天差地别
- **方法论的使用**: 标注禁用人群——专业梗拜年「严肃导师不适合」；标注禁用场景——「拉肚子时慎用，别问我为什么」
- **结论**: 禁用提示越简短越欲言又止，喜剧效果越强
- **结果**: 「别问我为什么」式留白成为固定句式

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写技巧清单文：「我教了读者一堆歪招，要不要提醒下风险」
2. 单条技巧有风险敞口：「这条不是人人都适用，怎么提一嘴」
3. 提示写出来像说明书：「『注意』『慎用』写得太干，怎么变成梗」
4. 怕读者滥用：「教人糊弄的话术，怕人天天用翻车」

### 语言信号

- "慎用/不适用于/别乱用/有个前提"
- "用多了会怎样/剂量/上限/一周最多一次"
- "对XX人没用/XX情况除外"
- "use with caution / not applicable if / at your own risk / don't overdo it"

### 与相邻 skill 的区分（初稿）

- 与 `disclaimer-device`（免责声明）: 本 skill 是**条目级**的剂量标注，跟在每条技巧末尾；免责声明是**全文级/段落级**的责任切割（「本文纯属玩梗」）。粒度不同，同篇文章往往两者都有：文末免责声明保命，条目间慎用提示造梗。
- 与 `positive-landing`（正能量兜底）: 本 skill 是**随条目**的即时刹车（每条技巧配一句）；正能量兜底是**结尾**的总刹车（全文最后一段回归正确价值观）。一个管局部剂量，一个管整体着陆，顺序上先用本 skill 逐条控剂量，结尾再用兜底收整体。

## E — 可执行步骤 (Execution)

1. **逐条过风险**
   - 完成标准: 把清单中每条技巧按「失效条件/剂量上限/禁用人群」三类各问一遍，有风险的条目标记出来

2. **给有风险的条目配标注**
   - 完成标准: 每个标记条目末尾写出一句 ≤20 字的提示，且归类明确（失效条件/剂量/禁用人群三选一）
   - 判停条件: 某条目三类问题都答「无风险」——判停，该条不加提示（P-20 not_applicable：技巧本身无风险时强行加提示显得啰嗦）

3. **把标注改写成梗**
   - 完成标准: 删掉「注意」「慎用」等说明书词，替换为夸张后果（「有点费老板」式）或欲言又止留白（「别问我为什么」式），朗读一遍确认像玩笑不像警告

4. **核对位置与密度**
   - 完成标准: 提示紧跟对应条目末尾而非汇总文末；全文提示密度与技巧危险度匹配，危险条目无一漏标

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 技巧本身零风险：强行加提示显得啰嗦（P-20 明确标注 not_applicable）
- 严肃操作教程（医疗/驾驶/安全规程）：这些场景的剂量标注是法律责任，必须写正式警示语，不能造梗
- 非清单文体：单点深度文没有「逐条」结构，提示应融进行文逻辑而非挂后缀

### 作者在语料中暴露的失败模式（反例支撑）

- ce-08 把糊弄话术当长期策略反复使用：进度缺口复利式累积，同一借口边际效用递减，导师信任额度被逐次透支，开学/答辩节点集中清算——不标注「这不能常用」，读者就把应急话术当常态
- ce-19 查岗应对术被高频滥用：话术有效性建立在「稀缺性」上，高频缺勤使任何话术失效，问题性质从「应对技巧」升级为「态度问题」，技巧层无解——正解正是毕导自己演示的标注法：「本方法只适用于偶尔被抓的情况；你要是老被抓，直接延毕吧」

### 作者的盲点 / 局限

- 玩梗式提示划的是幽默边界，挡不住真较真的读者；「别问我为什么」在法律意义上不构成有效警示
- 提示密度过高会让清单文节奏破碎，毕导语料中标注只挂在真有风险的条目上，并非每条必配

### 容易混淆的邻近方法论

- `disclaimer-device`: 条目级剂量标注 vs 全文级责任切割
- `positive-landing`: 随条目的即时刹车 vs 结尾的总着陆
- `extreme-extrapolation`: 剂量上限常用离谱外推呈现（300人→公司倒闭），但外推在这里服务于风险提示而非清单收束
