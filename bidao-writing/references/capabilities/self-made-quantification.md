# 自造量化体系：给不可量化之物发明指数、单位与定律

## R — 原文 (Reading)

> 如果我们定义相对摸鱼指数=（一起旅游+一起娱乐）/（一起上课+一起科研+一起企业课题+一起开展新方向），则有下表。……我这特么相对摸鱼指数已经超过了1啊！
>
> — 毕导, 《我的导师抓出了组里最爱摸鱼的人结果竟然是》

## I — 方法论骨架 (Interpretation)

核心机制是**喜剧工程学**：为摸鱼、份子钱、有钱程度这类主观社会现象，发明一套带公式、单位、分级的完整伪度量体系，把主观判断客观化——形式越正经，内容越荒唐。
固定三步成文：① **命名**——起一个"XX指数/XX比/XX定律"式名称，或自造度量单位（油价文造"一古"）；② **定标**——给出显式公式与变量定义，设分级锚点（五虎上将、0-10分、"超过1即为XX"）；③ **排名**——代入真实样本算分、列表、排序，最后推出极值或荒谬结论。
两个增效件：结论若是"巡回婚礼"式荒谬建议，张力最大；排名结果若反转落在作者自己头上（自己才是摸鱼王），喜剧与自嘲一次完成。
造得好的体系可跨篇复用，成为作者的可引用资产。

## A1 — 毕导的应用 (Past Application)

### 案例 1: 《我的导师抓出了组里最爱摸鱼的人结果竟然是》（c07）
- **问题**: 导师发问卷互评抓摸鱼，这个经历怎么写成文
- **手法**: 自定义"相对摸鱼指数"公式，把全组9人问卷数据逐项算分、列表排序，最后发现自己高达1.36、超过1成为"被摸熟的鱼"
- **效果**: "悬念开场→公式定义→数据表→反转自嘲"完整叙事链；该指数成为公众号长期复用的自有梗

### 案例 2: 《国庆咋人人结婚啊》（g-22）——份子钱函数建模
- **问题**: "随多少份子钱、何时办婚礼最赚"怎么写得有理有据
- **手法**: 设朋友有钱指数 f(t)=m+nt、朋友亲密指数 g(t)，定义份子钱 F(t)=f(t)g(t)，按"定义变量→建立函数→求极值"的论文路径推导
- **效果**: 推出"巡回婚礼，拟邀"的荒谬结论，形式严谨与结论离谱的对撞成为全文最大笑点

### 案例 3: 《海底捞点什么菜最贵》/《油价大涨》——自造度量衡
- **问题**: 火锅菜品、油价的横向比较缺一把好用的尺子
- **手法**: 发明"一口价""价乐比"等专属比较指标，油价文自造单位"一古"
- **效果**: 比较维度一目了然，自造名词本身成为记忆点与弹幕梗

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想吐槽一个主观现象（谁最摸鱼/谁最抠/谁最卷），不想显得空口无凭
2. 做横向测评/排名文，现成的评分维度都不合身，需要自己的尺子
3. 计算类选题想沉淀一个可跨篇复用的"自有概念"
4. 文章需要一个能被读者截图引用的公式/表格记忆点

### 语言信号

- "怎么让吐槽显得有理有据 / 想给XX打个分、排个名"
- "想造一个指数/公式/单位来衡量XX"
- "含XX量 / XX指数 / 评分体系 / 量化一下"
- "invent a metric / fake formula / custom index / scoring system"

### 与相邻 skill 的区分（初稿）

- 与 `mock-academic-packaging` 的区别: 本 skill 是**体系级造词**——发明新名词、新公式、新单位，完成"命名→定标→排名"整套工程；伪学术包装是**文体级错位**——借用现成的定律腔、摘要腔。一个是"造"，一个是"借"。
- 与 `pseudo-precision-numbers` 的区别: 伪精确是**句子级**单点数字，给感受配过载精度、用完即弃；本 skill 是**篇章级**体系，数字只是体系的输出物。

## E — 可执行步骤 (Execution)

1. **命名指标**
   - 完成标准: 产出一个"XX指数/XX比/XX定律"式名称，该名称脱离上下文也能独立成句、可被引用

2. **定义公式与变量**
   - 完成标准: 写出显式公式（如 A=(B+C)/(D+E+F)），每个变量配一行口语化定义，读者不看正文也能代入
   - 判停条件: 若公式需要3个以上嵌套括号才能成立，砍变量——体系要假得简洁

3. **定标分级**
   - 完成标准: 给出至少一个分级锚点（如"五虎上将""0-10分""超过1即被摸熟"），让数值有判读标准

4. **算分排名出表**
   - 完成标准: 至少3个真实样本代入公式，产出按指标排序的数据表，表中数字可手工复算

5. **推出结论**
   - 完成标准: 结论为以下三者之一：极值发现 / 荒谬行动建议 / 反转落在作者自己头上
   - 判停条件: 若排名结果会真实得罪具体出场人物，改用荒谬结论收尾，不做真人排名

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 严肃财经/政策/健康分析——伪建模一旦脱离喜剧语境，会被当成真模型传播误导
- 样本极少却想下全称结论时——先回 `empirical-writing` 补数据或加声明

### 语料中的失败模式

- **单点数据支撑全称结论**（ce-54,《女生化一次妆有多贵》）: 单次测量没有误差范围，结论普适性不成立；不主动声明局限，专业读者会用更苛刻标准攻击全文——自造体系也要前置"粗粗计算，仅供参考"，把适用边界抢在自己手里。
- **小样本被外推成普适定论**（ce-56,《共享单车怎么骑最划算》）: 一地一天的测评若不显式限定范围，读者将局部结论外推到全国全量，招致"以偏概全"质疑——指数排名后必须标注样本口径与时间范围。

### 局限

- 同一体系的喜剧价值随复用次数递减，一个指数最多跨几篇反复调用
- 造体系的构思成本远高于造金句，不适合短平快选题

### 容易混淆的邻近方法论

- `mock-academic-packaging`: 造体系（本 skill）vs 借文体（彼 skill）
- `pseudo-precision-numbers`: 篇章级工程（本 skill）vs 句子级数字（彼 skill）
- `price-anchor-conversion`: 造新单位（本 skill）vs 借现成消费品当单位（彼 skill）
