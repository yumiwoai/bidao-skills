# 软广无缝植入：广告从正文梗生长＋明确标注

## R — 原文 (Reading)

> 如果你爱吃小龙虾又爱喝酸奶，就可以开发个小龙虾酸奶……主要技术上就被"卡脖子"了！……那是乳业为了攻克技术难题设立的研发中心，专治"卡脖子疑难杂症"。
>
> — 毕导, 《如何在导师面前有效刷脸？导师：你小子搁这等我呢》（另见《救命！跟老板同时在厕所蹲麻了》转场词"从肠计益"、《如何培养一名高素质老板》文末标注"广 告"）

## I — 方法论骨架 (Interpretation)

商业合作文的整套工序：让广告从正文的内容逻辑里长出来，而不是打断内容插进来。五个要点：
① **先内容后产品**——先把正文的内容逻辑写完整，再回头看哪个环节自然需要这个产品；产品与选题毫无连接点时宁可换选题也不硬接；
② **让产品以"解决方案"身份登场**——正文制造一个需求缺口（换脸的破绽是光线、拉屎的后续是肠道），产品恰好填上；
③ **造转场桥**——用一个谐音词或过渡句完成滑轨切换（拉屎话题转益生菌："从肠计益"），转场词本身要承担笑点；
④ **广告段不降格**——与正文同规格同工艺：正文做对照实验，广告段也做控制变量实验并引真实文献（免烫衬衫商单），语气、密度、人设不断层；
⑤ **明确标注**——文末老老实实标"广告"二字，信任是账号的长期资产，藏着掖着换来的只有软文质疑。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《如何在导师面前有效刷脸》→ 乳业国创
- **问题**: 导师刷脸主题与乳业广告八竿子打不着
- **方法论的使用**: 正文先玩"小龙虾酸奶"梗→引出酸奶技术"卡脖子"→再引出乳业为攻克卡脖子设立的研发中心
- **结论**: 广告顺着正文梗的逻辑链自然生长出来
- **结果**: 读者滑进广告不觉突兀，商单完成内容化

### 案例 2: 《救命！跟老板同时在厕所蹲麻了》→ 益生菌
- **问题**: 厕所尴尬话题要平滑转向益生菌产品
- **方法论的使用**: 拉屎话题→肠道健康→益生菌，转场造词"从肠计益"，结尾标注广告
- **结论**: 转场桥本身成为全文最响的包袱之一
- **结果**: 广告段传播力不输正文

### 案例 3: 《我从梦华录学到了管理老板的7大技巧》广告段（c20，免烫衬衫商单）
- **问题**: 商单段落最容易人设塌方（多数作者广告段降格为叫卖体）
- **方法论的使用**: 把商单做成控制变量洗烘对比实验：普通纯棉 vs 免烫衬衫同机洗涤实拍对比，并引用真实学术文献（Textile Progress, 2012）佐证免烫工艺
- **结论**: 广告段保持"毕导式实证"人设不塌
- **结果**: 广告实验化成为商单内容化的标准范式，人设与商业双赢

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 接了商单/合作：「这个广告怎么写才不硬」
2. 广告段一写就变成叫卖体：「怎么让广告段不塌人设」
3. 产品和账号选题八竿子打不着：「这单接不接、怎么接」
4. 担心发广告掉粉：「怎么在商业化和读者信任之间两全」

### 语言信号

- "接了商单/广告/推广/合作，怎么写"
- "软广/植入/带货/恰饭，怎么自然过渡"
- "广告段太硬/掉人设/怕被骂软文"
- "sponsored content / native ad / seamless product placement / how to write an ad"

### 与相邻 skill 的区分（初稿）

- 与 `disclaimer-device`（免责声明）: 广告标注是利益关系声明（法律与信任义务），免责声明是内容边界切割（"别当真"）。ce-56 显示两者是一体两面：无广声明（"是广告我这辈子不能喝可乐"）与广告标注共用同一套信任逻辑，但适用对象相反——无广时要声明排除嫌疑，有广时要标注履行义务。
- 与 `caution-dosage-note`（慎用提示）: 本 skill 处理广告怎么进来；慎用提示处理技巧怎么刹车。商单文中的产品使用提示可复用慎用提示的写法。

## E — 可执行步骤 (Execution)

1. **先写正文**
   - 完成标准: 把正文内容逻辑写完整，全程不考虑广告，正文独立成立

2. **找需求缺口**
   - 完成标准: 指出正文中"哪个环节自然需要这个产品"，用一句话写出"正文逻辑→产品"的因果链
   - 判停条件: 找不到任何真实连接点——判停，换选题或推掉此单，严禁硬接（P-17 明令）

3. **造转场桥**
   - 完成标准: 写出一个过渡词/过渡句（谐音优先），单独念出来也有笑点

4. **按正文同规格写广告段**
   - 完成标准: 广告段的工艺与正文同档（正文有实验广告就有对照、正文有数据广告就有实测），通读全文听不出语气断层

5. **明确标注**
   - 完成标准: 文末出现无歧义的"广告"标注字样，位置显眼不藏匿

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 产品与主题毫无连接点时（P-17 明令：先换产品或换选题，不要硬接）
- 产品无法通过作者真实检验时——实验化广告的前提是你真用过，假实测是双重欺骗
- 账号正处于信任建立初期、尚无"实证人设"存量时，高频接广会直接扼杀账号

### 作者在语料中暴露的失败模式

- 广告段降格：语气突变叫卖体，正文攒下的人设一段败光（c20 验证记录明确指出"多数作者广告段降格"，实验化是反例解法）
- 不标注广告：ce-56 的机制——品牌相关内容天然触发利益关联警觉，不标注的软广被识破后公信力受损远超明码标价
- 硬接产品：转场没有逻辑桥，读者能摸到接缝，评论区直接翻车

### 作者的盲点 / 局限

- 整套工序依赖"亲测实证"人设的存量积累，冷启动账号难以复制实验化广告
- 内容化越深，广告转化路径越长，对只看转化数据的甲方需要提前管理预期

### 容易混淆的邻近方法论

- `disclaimer-device`: 利益声明 vs 内容边界，一体两面
- `positive-landing`: 广告文同样需要价值观着陆（如招聘文切割"以下文为准"），两者常同篇出现
