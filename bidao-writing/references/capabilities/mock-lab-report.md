# 伪科研实验报告体：用论文建制给鸡毛蒜皮立规矩

## R — 原文 (Reading)

> 【实验设计】【实验选品】【实验声明】本文样本量有限……最终结果仅供参考。
>
> — 毕导, 《双11送的护肤品小样划算吗？单价1000的贵妇精华竟然只能倒出一半》

## I — 方法论骨架 (Interpretation)

把生活测评按论文的栏目建制完整重排：【实验设计】→【实验选品/变量】→【实验过程】→【实验结论】，并前置【实验声明】。操作要点：
① **栏目名一个不能少**——论文有的栏目生活实验都要有（对照组、变量、样本声明），建制完整度本身就是笑点密度；
② **真做测量**——用天平、PH试纸、竹签等真实工具产出真实数据，戏仿的壳必须装实证的核（与「真做实验」原则联动）；
③ **声明先行**——实验开始前就交代样本局限（「样本量仅1张脸，仅供参考」），既占学术规范高地又防专业读者打脸；
④ **过度正经是方向**——把捞汤做到对照组+时间梯度+曲线拟合+流体力学机理分析的论文级完整度，形式越隆重，内容越鸡毛蒜皮，反差越好笑。

## A1 — 毕导的应用 (Past Application)

### 案例 1: 双11小样文
- **怎么用的**: 测评小样是否划算，设【实验设计】【实验选品】【实验声明】栏目，声明样本量有限，每个样本出结论卡
- **效果**: 购物吐槽被学术建制收编，贵妇精华「只能倒出一半」的结论有了论文式权威

### 案例 2: 柚子皮实验（c22）
- **怎么用的**: 用裹PH试纸的竹签插柚子顶部/侧面/底部三点测皮厚，当场剖开验证（头顶皮厚3.5cm），按【实验思路】【实验过程】【实验结论】成文
- **效果**: 买菜琐事写成可复现的挑果方法论，实验报告小标题成为可复用模板

### 案例 3: 捞汤文（c26，代表作）
- **怎么用的**: 天平+滤纸+烧杯测5种捞紫菜蛋花汤方法，对照组2.824g、变量梯度5s-40s、画出时间-收获曲线，并用玻尔兹曼分布做机理分析，被食堂阿姨叫滚收尾
- **效果**: 「毕导式实验文」代表作，称重数据表被大量转发，过度正经本身即喜剧

### 案例 4: 免烫衬衫商单（c20）
- **怎么用的**: 把商单做成控制变量洗烘对比实验，还引用真实学术文献佐证原理
- **效果**: 广告段保持实证人设不塌，商单内容化的标准范式

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 测评升级：「测评/对比文怎么写出差异化，不像网上口水文」
2. 小事隆重化：「想把一个生活小事写得一本正经地好笑」
3. 数据组织：「手上有一堆实测数据，怎么组织成文章」
4. 商单保人设：「接了广告但不想广告段塌掉内容风格」

### 语言信号

- "测评/实测/对比测试/横向评测/实验报告"
- "对照组/控制变量/样本量"
- "小题大做/杀鸡用牛刀/一本正经"
- "mock experiment / lab report style / pseudo-scientific / controlled test"

### 与相邻 skill 的区分

- 与伪学术包装（V-09）的区别: 本卡是体裁结构层（栏目建制）；伪学术包装是词句层（定律、术语、摘要腔），常叠加使用
- 与 `interview-story-collection` 的区别: 本卡的素材来自亲自测量；故事集素材来自采访他人，是两条不同的内容供应链

## E — 可执行步骤 (Execution)

1. **选一个鸡毛蒜皮的问题**
   - 完成标准: 问题小到不配被研究（捞汤、挑柚子、挤小样），且可用简单工具测量
2. **搭论文栏目骨架**
   - 完成标准: 写出【实验设计】【实验选品/变量】【实验过程】【实验结论】【实验声明】五栏标题，缺一补全
3. **真做测量并记录**
   - 完成标准: 设对照组与至少一个变量梯度，产出真实数据表（数值精确到小数）；无真实数据则本步不通过
   - 判停条件: 测量成本远超内容价值或涉及安全/伦理风险 → 换题，不硬做
4. **先写实验声明**
   - 完成标准: 在正文前部交代样本量与口径局限（「样本量仅N，仅供参考」），位置必须在被质疑之前
5. **逐样本出结论卡**
   - 完成标准: 每个样本/方法配一句结论卡，全部数据可汇总成一张表
6. **机理升华收尾**
   - 完成标准: 结尾用真实学科原理（流体力学、分布律）做一段「机理分析」，隆重感拉满后落地

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 时间敏感的快讯类内容（做实验周期长）
- 读者无学术语境的纯大众软文——栏目梗无人接
- 没有条件真做测量时——只有栏目空壳没有数据，戏仿变欺骗

### 语料中观察到的失败模式

- ce-54（单次称量就下结论）：单点数据支撑全称结论且不声明局限，会被专业读者打脸——实验声明不是示弱，是防翻车标准动作
- ce-56（主观测评不做边界声明）：小样本结论被外推为普适定论，招致「软文/以偏概全」质疑——抽样范围与「无广」声明是测评文双保险
- 借壳不装核：只抄栏目名没有真数据，文章既不好笑也不可信

### 局限

- 强依赖理工科/学术身份人设；非学术人设作者戏仿可信度打折
- 每篇需要真金白银的测量投入，产能受限

### 容易混淆的邻近方法论

- 自造量化体系（V-10，发明指标公式）: 那是造度量衡；本卡是借论文建制做流程，一个造尺一个走流程
