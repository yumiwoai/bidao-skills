# 实证写作：真做实验、真调查，笨功夫即壁垒

## R — 原文 (Reading)

> 随手一捞：2.824g……脸皮薄慢捞5s：8.095g；脸皮厚慢捞15s：12.589g；不要脸慢捞30s：27.055g；毕导终极不要脸慢捞40s：45.640g。
>
> — 毕导, 《如何在食堂捞到最多的紫菜蛋花汤？亲测5种方法后食堂阿姨叫我滚》

## I — 方法论骨架 (Interpretation)

核心机制是**生产方式的差异化**：为写一篇文先花真金白银和体力做可复现测量——真买、真称、真数、真跑平台，拍照留证。网上口水文无法复制一手数据与亲历现场，笨功夫直接构成内容壁垒。
固定工序五步：① 选一个网上只有口水答案的问题；② 设计笨办法（称重/计数/对照组/变量梯度），样本量小也要声明；③ 亲自执行，原始数据逐条记录，社死现场（被围观、被阿姨叫滚）单独记下；④ 数据以表格/清单成文，每个数字可回溯，测量过程写成带画面的故事；⑤ 实验前或文末声明样本局限与适用范围。
增效件：把社死过程写进正文（"尽量忽视周围异样的旁光"），枯燥测算即刻变成有画面的叙事；测量做到论文级完整度（对照组、曲线、机理分析）时，过度正经本身就是笑点。

## A1 — 毕导的应用 (Past Application)

### 案例 1: 《如何在食堂捞到最多的紫菜蛋花汤》（c26）——代表作级定量
- **问题**: 食堂免费汤怎么捞到最多紫菜蛋花
- **手法**: 精度天平+滤纸+烧杯，对照组"随手一捞"2.824g起步，逐法称重5种捞法，测5s-40s时间-收获曲线，还用流体力学原理做机理分析
- **效果**: 论文级完整度让"过度正经"本身成为喜剧，称重数据表被读者大量转发

### 案例 2: 《一只小龙虾能吃到多少肉》（P-05）
- **问题**: "小龙虾肉少"人人会说，没人给过数
- **手法**: 真剥70只虾逐只称重，得出快24g的虾可食部分只有5.1g、可食率21%
- **效果**: 一手数据成为全文论证地基，也喂饱了标题与换算锚点（每克1.7元）

### 案例 3: 《海底捞点什么菜最贵》（f28）——社死现场入文
- **问题**: 菜品单价对比过程枯燥，读者容易流失
- **手法**: 掏出随身携带的大砧板进店逐片数肥牛，并如实写下"尽量忽视掉周围异样的旁光"
- **效果**: 测量+自嘲双料，过程叙事取代干巴数据，"较真"人设落地

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 选题撞车严重，网上已有大量口水文，必须做差异化
2. 写测评/辟谣/价格对比，需要一手数据撑腰
3. 初稿缺真实细节与画面感，通篇都是"我觉得"
4. 想长期建立"较真/实测派"人设与内容护城河

### 语言信号

- "怎么写出差异化 / 不想写口水文 / 网上都写过了"
- "要不要真的去测一下 / 实测 / 亲测 / 称重 / 统计了一遍"
- "文章没有真实感 / 缺细节 / 没画面"
- "first-hand data / actually tested / field research / DIY experiment"

### 与相邻 skill 的区分（初稿）

- 与伪科研实验报告体（V-07）的区别: 报告体是**结构外壳**（【实验设计】【实验声明】栏目建制），本 skill 是**生产方式**（真花时间花钱测量）。两者常叠加——真做实验、用报告体成文——但可独立存在：真测量用口播体写也成立。
- 与 `self-made-quantification` 的区别: 实证产出**真实测量数据**（2.824g可复现），自造量化产出**虚构指标体系**（摸鱼指数无实物对应）。一个求真，一个造梗，数据位不可混用。

## E — 可执行步骤 (Execution)

1. **选定可实测问题**
   - 完成标准: 问题同时满足三条件——网上无一手数据答案 / 测量成本（钱+时间）可承受 / 结果有反差潜力
   - 判停条件: 若测量涉及安全或伦理风险，判停，换选题（P-05 边界）

2. **设计笨办法**
   - 完成标准: 写出测量方案三要素——工具（秤/尺/计数）、样本量（≥5，达不到则注明单次）、对照或梯度设计（至少一个对照组）

3. **执行并留证**
   - 完成标准: 获得逐条原始数据记录+现场照片≥2张；社死/意外瞬间当场记下一句现场描写

4. **数据成文**
   - 完成标准: 数据以表格或清单呈现，每个数字可回溯到测量记录；过程部分含至少一处带画面的现场描写
   - 判停条件: 若某数字无法回溯到原始记录，删除该数字而非虚构补齐

5. **声明局限**
   - 完成标准: 实验开始前或文末写明样本量、时间地点与适用范围（"仅代表X月X日调查，仅供参考"句式），并用"期待后人改进"式开放姿态收尾

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 测量成本远超内容价值（为一句话花数千元）
- 涉及安全/伦理风险的实验（入口、通电、真人测试未获同意）

### 语料中的失败模式

- **单次称量就下全称结论**（ce-54,《女生化一次妆有多贵》）: 单点数据没有误差范围，普适性不成立；不声明局限会被专业读者用更苛刻标准攻击，作者丧失定义结论适用范围的主动权——局限声明要放在实验开始前，而非被质疑之后。
- **小样本测评被当成广告或定论**（ce-56,《共享单车怎么骑最划算》）: 品牌对比天然触发利益关联警觉，小样本结论不限定范围会被外推成普适判断——边界声明+无广利益声明是双保险，越主观的内容越要用规范声明换信任额度。

### 局限

- 笨功夫产能低，一篇需数天测量，无法支撑日更频率
- 可实测选题有限；纯数据内容易被平台判为低质堆砌，必须配叙事包装

### 容易混淆的邻近方法论

- 伪科研实验报告体（V-07）: 生产方式（本 skill）vs 结构外壳（彼 skill）
- `self-made-quantification`: 真实测量（本 skill）vs 虚构体系（彼 skill）
