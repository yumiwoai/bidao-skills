# 结尾互动装置：楼层福利＋奖品呼应正文梗

## R — 原文 (Reading)

> 留言区福利：1楼可获得能踩点的计时器一个，15楼可获得不卡脖子的围脖一条，25楼可获得不能刷脸的刷子一把。……（油价文）1楼可获得兰博基尼代金券50元。
>
> — 毕导, 《研究生开组会时都是什么鬼样子？我总结了15种类型》/ 油价大涨文（g-05 语料）

## I — 方法论骨架 (Interpretation)

公众号推文结尾的固定两件套：抛一个问题邀读者补充/对号入座，再设"留言区楼层福利"驱动抢楼互动。操作要点：
① **问题要低门槛可回答**——对号入座式（"看看你是哪种"）或素材补充式（"欢迎在留言区补充"），让读者有话可说；
② **楼层固定三档**——1楼/十几楼/25楼，形成读者可预期的固定栏目（语料抽样28篇几乎全部如此配置）；
③ **奖品必须呼应正文梗**——奖品不是抽奖诱饵，而是正文最后一个包袱：组会文送"能踩点的计时器""不卡脖子的围脖""不能刷脸的刷子"，基金文送《绿光》专辑、绿色心情雪糕和韭菜（全呼应"基金变绿"）；
④ **奖品要便宜或离谱**——实物是小玩意儿，或是"兰博基尼代金券50元"式的荒诞代金券，错位感越强越好笑；
⑤ **格式固定**——"留言区福利：1楼可获得……"的栏目化写法，让老读者形成期待。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《研究生开组会时都是什么鬼样子？我总结了15种类型》
- **问题**: 类型学盘点文收尾，需要把"对号入座"冲动转化为留言
- **方法论的使用**: 先邀读者补充未收录的新类型，再设1/15/25楼福利，奖品全部呼应正文梗（踩点计时器、不卡脖子围脖、不能刷脸刷子）
- **结论**: 评论区变成读者补类型的二次创作现场
- **结果**: 互动与内容同源，留言质量高

### 案例 2: 《基金大亏故事：朋友两年亏掉200w》
- **问题**: 亏损主题沉重，互动设计稍有不慎就显轻浮
- **方法论的使用**: 楼层奖品设为孙燕姿《绿光》专辑、绿色心情雪糕、韭菜——全部呼应"基金变绿"的梗
- **结论**: 奖品本身成为全文最后一个包袱
- **结果**: 沉重的主题在互动区完成最后一次幽默落地

### 案例 3: 《如何做一个体面的穷人》《一只小龙虾能吃到多少肉》
- **问题**: 消费计算文的评论区运营
- **方法论的使用**: 穷人文设1楼送50根碎冰冰、15楼送披萨、25楼送锅；小龙虾文送虾壳垃圾分类袋
- **结论**: 奖品与"穷人/剥虾"主题一一呼应
- **结果**: 福利栏目成为账号固定签名，读者为抢楼而来

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 推文写完要做评论区运营：「结尾怎么设计才能拉留言」
2. 留言区长期冷清：「怎么让读者愿意开口」
3. 想给读者发福利：「不想搞正经抽奖，怎么发得有意思」
4. 盘点/图鉴类文章收尾：「怎么诱导读者对号入座并补充」

### 语言信号

- "留言区福利/楼层奖/抢楼/1楼送"
- "评论区互动/拉留言/冷启动评论/让读者说话"
- "结尾互动/文末福利/奖品怎么设计"
- "comment engagement / comment section prize / floor rewards / drive comments"

### 与相邻 skill 的区分（初稿）

- 与定制"在看"引导文案（P-10 原则）: 本 skill 运营的是评论区楼层（留言数据）；在看引导运营的是"点在看"动作（推荐流量），话术每期定制。位置相邻但目标动作不同。
- 与 `language-meme-rewrite`（语言梗化改造，V-13）: 奖品命名需要调用梗化改造手艺，但本 skill 的核心是"奖品-正文梗呼应"的装置设计与楼层机制，不止于修辞。

## E — 可执行步骤 (Execution)

1. **写邀答问题**
   - 完成标准: 写出一句低门槛问题，读者看完3秒内能想到自己的答案（对号入座或补充经历型）

2. **定三档楼层**
   - 完成标准: 写下"1楼/X楼/25楼"三档，X取10-20之间的具体数字

3. **回正文选梗配奖品**
   - 完成标准: 从正文挑出3个最强的梗，每梗配一个奖品；逐一核对"奖品→梗"的呼应关系能被人一眼看懂
   - 判停条件: 想不到任何呼应梗的奖品时判停——改用便宜实物+梗化命名，严禁用与正文无关的贵重奖品凑数

4. **按栏目格式成文**
   - 完成标准: 写成"留言区福利：1楼可获得……X楼可获得……25楼可获得……"的固定句式，奖品数量单位齐全（一个/一条/一把）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 平台无留言功能或楼层不可见（P-09 明确标注）——机制失效
- 严肃公告、讣告、声明类文章——抢楼氛围与文本气质冲突
- 正文本身无梗可呼应时——硬配奖品会变成普通抽奖

### 作者在语料中暴露的失败模式

- 奖品与正文无关：浪费"全文最后一个包袱"的位置，互动沦为普通抽奖（语料成功样本全部梗-奖品一一呼应，反向印证无关即失败）
- 奖品太贵重：吸引羊毛党而非读者，评论区被抽奖号淹没，玩梗氛围被冲掉
- 问题太宽泛（"大家怎么看"）：读者无从下手，留言冷场

### 作者的盲点 / 局限

- 完全依赖微信公众号的楼层可见机制，迁移到无楼层概念的平台需整体改造
- 奖品需要真实兑现，栏目化承诺累积下来是持续的成本与履约负担

### 容易混淆的邻近方法论

- P-10 定制在看引导: 评论区楼层运营 vs "点在看"话术定制，动作目标不同
- `disclaimer-device`: 福利承诺也是承诺，奖品描述别越过广告法红线（虚假有奖活动是真风险）
