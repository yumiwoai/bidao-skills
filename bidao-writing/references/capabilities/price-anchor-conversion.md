# 生活化换算锚点：把万物折成奶茶和矿泉水

## R — 原文 (Reading)

> 以清华大学为例，2022年度的采购金额足足高达188万元！而清华在校生约5w人，等于每个人要看37块钱的文献！够吃92.5个清芬包子了！
>
> — 毕导, 《我扒了全国各大高校的知网采购费，被坑得最惨的学校竟然是它》

## I — 方法论骨架 (Interpretation)

核心机制是**用物价直觉代替数字感知**：读者对"188万"无感，但对"92.5个包子"立刻有体感。做法是不再用"元"作单位，而是建立作者专属的**换算宇宙**——固定几把大众消费品度量衡（清芬包子、农夫山泉、一点点奶茶、视频会员），任何抽象金额都除成锚点商品的个数。
操作四步：识别文中读者无体感的量级数字→按读者画像选锚点商品→算出倍数（保留1位小数，"92.5个"比"92个"更较真更好笑）→紧跟一句情绪感叹收束（"都够我一天生活费了"）。
两个杠杆：锚点固定复用（永远包子/矿泉水/奶茶）会沉淀为个人风格资产；换算方向可逆用——把闲置物换算成工时报酬（"落灰的都是你的工资"），痛感同样成立。

## A1 — 毕导的应用 (Past Application)

### 案例 1: 《知网采购费》——188万=92.5个包子
- **问题**: 高校采购费这种机构级巨款，读者看完无感就划走
- **手法**: 先除以在校生人数得"每人37元"，再折成清华食堂的92.5个清芬包子
- **效果**: 愤怒有了具体抓手，深扒文的数据瞬间可感，"清芬包子"成为全文传播点

### 案例 2: 《一只小龙虾能吃到多少肉》（P-04）
- **问题**: 小龙虾贵不贵，单价数字说了不算
- **手法**: 一只7.1元换算成"包场腾讯爱奇艺优酷b站网易云qq音乐全网会员"；每克1.7元换算成"补三毛买一整瓶农夫山泉"
- **效果**: 贵不贵瞬间可判，价格吐槽的笑点与说服力同时成立

### 案例 3: 《女生护肤一次有多贵》（g-24）
- **问题**: 精华按克计价，"2元/克"读者没有痛感
- **手法**: 建立度量衡"1g=一瓶农夫山泉、1mL=一杯一点点、1mL=一碗烤冷面"，挤1g精华=挤掉一瓶水
- **效果**: "万物皆可折成奶茶"的换算宇宙成型，后续文章低成本复用

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 文中出现大额/抽象数字（百万级金额、克数、毫升数），担心读者无感划走
2. 写价格吐槽/省钱攻略，想让"贵"或"值"产生真实痛感
3. 深扒文需要把机构级数字翻译成读者的人话
4. 想沉淀个人风格的固定梗，让读者看到包子就想起你

### 语言信号

- "这个数字怎么写得有体感 / 怎么让读者觉得贵"
- "换算成奶茶/包子/矿泉水/视频会员"
- "XX块钱是什么概念 / 相当于多少杯奶茶"
- "price anchor / relatable comparison / convert to everyday items"

### 与相邻 skill 的区分（初稿）

- 与 `self-made-quantification` 的区别: 换算是**借**现成消费品当单位（包子、矿泉水），目标是"可感"；自造量化是**造**新单位新指数（一古、摸鱼指数），目标是"体系"。
- 与 `pseudo-precision-numbers` 的区别: 换算的数字服务于体感，越贴近日常越好；伪精确的精度服务于笑点，越过载越好。一个求"可感"，一个求"离谱"。

## E — 可执行步骤 (Execution)

1. **标记无感数字**
   - 完成标准: 通读初稿，标出所有超过读者日常量级的数字（≥3位数金额、克/毫升级计量、万级人数）

2. **选定锚点商品**
   - 完成标准: 选出1-3个目标读者每日高频消费的固定锚点（如奶茶/包子/视频会员），单篇锚点不超过3种且全文统一
   - 判停条件: 若锚点不是读者画像的高频消费品（对学生党用茅台），立即更换锚点

3. **完成换算**
   - 完成标准: 每个无感数字算出"=N个锚点"，N保留1位小数或整数，算式可手工复核；两次换算路径相同（先除人数再折商品）保持链条一致

4. **配感叹收束**
   - 完成标准: 每处换算结果后紧跟一句情绪句（"都够我一天生活费了"），完成"数字→画面→情绪"闭环
   - 判停条件: 若连续两个数字要用同一锚点，第二个改为直述，防止锚点疲劳

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 数字本身已直观（"3个人""9块9"无需再换算）
- 严肃财经分析——换算法是体感工具不是估值工具，用于真投资建议即不严谨（P-04 边界）

### 语料中的失败模式

- **线性直觉换算踩进档位陷阱**（ce-49,《薯条大份更划算？》）: 商家分量定价并非线性，恰恰利用消费者"大份=划算"的线性直觉在部分档位设价格陷阱——按线性比例外推的换算会把读者带进新误区，涉及"哪个档位最值"时锚点换算必须搭配实测档位。
- **锚点与读者画像错位**: ce-44《打工人一年懵懵懂懂白花多少钱》的成功在于把闲置衣物换算成工时报酬（"衣柜里落灰的都是你的工资"），锚点正中打工人；若给大学生读者用房贷、茅台做锚点，换算越精确越无感。

### 局限

- 锚点有保鲜期：奶茶涨价、包子换价，跨年度文章需更新锚点价格，否则换算失真
- 同一锚点在一篇内出现3次以上即疲劳

### 容易混淆的邻近方法论

- `self-made-quantification`: 借现成单位（本 skill）vs 造新单位（彼 skill）
- `pseudo-precision-numbers`: 求可感（本 skill）vs 求过载（彼 skill）
